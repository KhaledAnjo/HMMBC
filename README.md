# HMMBC
Bilingual (AR/EN) web app for preliminary construction material estimation and contractor offer comparison — built for the Jordanian market.

HM²BC — How Much My Building Cost?
## Features
- 🏗️ Three project types: Add Floor, Villa, Full Building
- 📊 Seven cost categories: Structure, Electrical, Plumbing, 
  Finishing, Aluminum, Parking Garage, Swimming Pool
- 🔍 Greater Amman Municipality validation checks
- 🤝 Contractor offer comparison with justified thresholds
- 📋 Classified contractors directory
- 💾 Local auto-save + signed JSON export/import
- 📄 PDF report export
- 🌐 Full Arabic RTL and English LTR interfaces

## Tech Stack
Vanilla JavaScript (ES Modules) · HTML5 · CSS3  
No backend · No build step · Works offline

## References
- Jordanian General Technical Specifications (Green Book)
- Greater Amman Municipality Building Bylaw 2018
- Jordanian Standard 1562/2004 (Swimming Pools)

## Usage
Open `index.html` directly in any modern browser.
No installation or server required.
